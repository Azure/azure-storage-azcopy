# AzCopy Sample Telemetry JSON Payloads

These are representative request bodies generated by the production `telemetry.Reporter` direct Application Insights path. Each lifecycle event is sent to `/v2.1/track` as one packed custom-event envelope. Numeric measurements share one `measurements` map instead of repeating dimensions in separate metric rows. The capture uses the sample app's real event objects and serializer but an in-memory HTTP client, so generating this file does not send telemetry.

The five copy and five sync attempts have the same payload shape; values such as IDs, timestamps, counters, and terminal status vary per attempt. The examples below use the first completed attempt of each command.
